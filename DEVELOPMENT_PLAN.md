# Togetherly Development Plan — after v1.8

## Current principle
Feature rich underneath; calm and obvious in daily use.

## Highest-value next candidates

1. **Doodle Guess** — reuse the existing drawing engine and game-session architecture.
2. **Promote to Memory** — save a Daily Question History entry, Scratchpad drawing or finished game drawing into Our Story.
3. **Contextual active-game shortcut** — only appear on Home while a Play Together game is actually active.
4. **Unread badge** — small notification count on More rather than another Home card.
5. **Production deployment** — real bundle ID, signing, HTTPS API, email delivery, store assets.

## Avoid
- adding permanent Home cards for every feature;
- turning settings into daily workflow;
- duplicating Calendar/List/Memory data inside Trips or games;
- adding more top-level tabs when an existing parent experience fits.
