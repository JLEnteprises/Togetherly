# Togetherly v1.9 — UX Polish Audit

## Product rule
Feature-rich underneath; quiet and obvious in daily use.

## Home
Home keeps the same small set of sections rather than adding feature cards.

### Today
- one compact card
- Calendar, Tasks, Daily Question and Check-in remain one-tap rows
- heavy row separators removed
- task summaries still elevate overdue steps, high priority work and active planning windows

### Scratchpad
- remains on Home
- defaults to a compact saved preview
- Text and Draw open the editor inline
- saved drawings show as a thumbnail
- Save collapses the editor
- Cancel restores the last saved state
- full Scratchpad remains available under Notes

### Across the distance
- participant names removed from the visible clock row
- each time uses that participant's identity colour
- accessibility labels still identify whose time is whose
- a small centre label shows `Same time` or the hour difference
- countdown and availability rows use direct human labels rather than technical headings

### Quick Actions
- compact filled controls rather than outlined dashboard buttons
- Play, Date idea, Tasks and Memory remain available
- an active game can surface as Continue without adding another Home section

## Photos + Albums
Photos and Albums are now one destination:

- `All photos` — every photo attached to a memory
- `Albums` — curated album cards with cover images, counts and descriptions
- album create/edit/delete and add/remove-memory actions are preserved
- the previous Albums route redirects to Photos > Albums

No album or photo database functionality was removed.

## Copy audit
User-facing text was reviewed across Home, Plan, Together, Us, More and feature screens. Development-style commentary was removed, including wording that described:

- why screens were grouped
- what had moved in a previous version
- forms being collapsed as an implementation choice
- features competing for attention
- parent experiences / feature architecture
- realtime/device implementation details when they were not needed by the user

Copy is now shorter and task-focused while privacy/security explanations that affect user decisions remain intact.
