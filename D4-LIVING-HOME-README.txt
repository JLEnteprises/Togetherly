Togetherly v1.14.3 — Release D4: Living Home

Scope
- Home surfaces the relationship state before secondary modules.
- Partner mood that needs attention becomes a direct one-tap “I’m here” response.
- Today is reduced to a short, readable attention list.
- Long-distance Home becomes one unified story: two local times, time difference, reunion countdown, next shared free window, and live distance when both locations are available.
- No database migration. No new dependency.

Run from the Togetherly project root:
  node APPLY_RELEASE_D4_LIVING_HOME.js

The installer runs frontend typecheck, server typecheck, and server logic automatically.
